01 · Persiapan

Alat & Bahan

Beberapa alat yang dibutuhkan untuk membuat kabel LAN dan melakukan koneksi antar dua laptop.

🔌

Kabel UTP

Kabel twisted pair yang digunakan sebagai media transmisi jaringan.

🔗

RJ45

Konektor yang dipasang pada ujung kabel UTP untuk koneksi Ethernet.

✂️

Tang Crimping

Digunakan untuk memasang dan mengunci kabel UTP ke konektor RJ45.

🧪

LAN Tester

Digunakan untuk memeriksa apakah susunan kabel sudah benar.

03 · Perakitan

Cara Merangkai Kabel LAN

Ikuti langkah berikut secara berurutan agar kabel dapat digunakan untuk koneksi jaringan.

01

Kupas Kabel

Kupas bagian luar kabel UTP dengan hati-hati hingga delapan kabel kecil di dalamnya terlihat.

02

Susun Warna

Pisahkan kabel dan susun sesuai standar T568A dan T568B untuk membuat kabel crossover.

03

Luruskan Kabel

Luruskan seluruh kabel kemudian rapikan ujungnya agar mudah dimasukkan ke RJ45.

04

Potong Rata

Potong ujung kabel menggunakan tang crimping agar panjang kedelapan kabel sama.

05

Masukkan RJ45

Masukkan delapan kabel ke konektor RJ45 sesuai urutan warna yang telah ditentukan.

06

Crimping

Tekan RJ45 menggunakan tang crimping hingga konektor terkunci dengan kuat.

07

Uji Kabel

Gunakan LAN Tester untuk memastikan seluruh jalur kabel terhubung dengan benar.

08

Hubungkan Laptop

Hubungkan kabel LAN yang telah selesai dibuat ke dua laptop melalui port Ethernet.

09

Siap Digunakan

Setelah koneksi berhasil, kedua laptop dapat berkomunikasi dan berbagi file.

04 · Peer To Peer

Hubungkan 2 Laptop

Gunakan kabel LAN crossover untuk membuat koneksi langsung antara Laptop 1 dan Laptop 2.

💻 Laptop 1

  1. Hubungkan kabel LAN ke kedua laptop.
  2. Buka Control Panel.
  3. Pilih Network and Internet.
  4. Pilih Network and Sharing Center.
  5. Klik Change adapter settings.
  6. Klik kanan Ethernet → Properties.
  7. Pilih Internet Protocol Version 4 (TCP/IPv4).
  8. Masukkan IP address berikut.
IP Address : 10.10.10.1
Subnet Mask : 255.0.0.0

💻 Laptop 2

  1. Buka pengaturan Ethernet seperti Laptop 1.
  2. Pilih IPv4.
  3. Gunakan IP address berbeda tetapi masih satu jaringan.
  4. Klik OK dan simpan pengaturan.
  5. Buka Command Prompt.
  6. Lakukan tes koneksi menggunakan perintah ping.
IP Address : 10.10.10.2
Subnet Mask : 255.0.0.0

ping 10.10.10.1
05 · File Sharing

Sharing File Antar Laptop

Setelah kedua laptop terhubung, file dapat dibagikan melalui Windows File Sharing.

  1. Pada laptop yang menyimpan file, klik kanan folder yang ingin dibagikan.
  2. Pilih Properties → Sharing.
  3. Klik Advanced Sharing.
  4. Centang Share this folder.
  5. Klik Permissions dan atur izin akses sesuai kebutuhan.
  6. Pada laptop kedua, tekan Win + R.
  7. Masukkan alamat IP laptop pertama.
\\10.10.10.1

Jika koneksi dan pengaturan sharing sudah benar, folder yang dibagikan akan dapat diakses dari laptop kedua.
